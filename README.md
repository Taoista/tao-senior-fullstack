# Tao Senior Fullstack

Skill pública de Codex para desarrollar y revisar aplicaciones fullstack con arquitectura mantenible, seguridad verificable, pruebas y entornos reproducibles.

## Instalación

Copia este repositorio en tu directorio personal de skills:

```bash
git clone https://github.com/Taoista/tao-senior-fullstack.git ~/.codex/skills/senior-fullstack
```

Abre una conversación nueva en Codex para que detecte la skill.

## Contenido

- `SKILL.md`: instrucciones de la skill.

## Uso

Invoca la skill por su nombre, `senior-fullstack`, o realiza una solicitud relacionada con su especialidad.
